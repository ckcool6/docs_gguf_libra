## 🛠️ 常用 Markdown 语法排版演示

### 1. 强调语法
* 这是 **加粗** 的文字。
* 这是 *斜体* 的文字。
* 这是 ~~带有删除线~~ 的文字。

### 2. 清单与列表
* 🟢 **第一步**：在 `docs/` 目录下新建 `.md` 文件
* 🟡 **第二步**：在文件顶部写好 `sidebar_position` 控制顺序
* 🔵 **第三步**：在本地浏览器 `localhost:3000` 查看效果

### 3. 高亮提示框（Docusaurus 特色功能）
Docusaurus 自带了非常漂亮的信息提示框，直接输入以下格式即可：

:::tip 提示
这是一个非常有用的**小贴士**，适合用来划重点！
:::

:::danger 警告
这是一个**危险警告**框，用来提醒读者注意避免踩坑。
:::
